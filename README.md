# Rysana Type

**Rysana Sans** and **Rysana Mono**, by [Rysana, Inc.](https://rysana.com)

- **Download:** [`rysana-type.zip`](https://github.com/rysana-os/type/releases/latest/download/rysana-type.zip): static TTF (plain and hinted), OTF, variable TTF, web WOFF2 and install scripts.
- **npm:** `npm i rysana-type` for the web fonts, a Next.js loader, CSS and the Mono cell-width helpers.
